One emoji for the [make.fun "One Emoji, One Dream Vacation" bounty](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35): a single emoji, nothing else, standing in for the trip of your dreams — judged on which one most makes a stranger want to book the flight.

## The entry

> 🌋

One code point (U+1F30B VOLCANO), four UTF-8 bytes. A volcano is a mountain and a faraway place at once — Iceland, Hawaii, Bromo — a whole landscape in one glyph: black sand, an erupting peak, the earth breathing. It is specific, not any holiday; surprising, not another island or palm; and it reads instantly at any size.

## Run it

`main.py` (Python 3, stdlib only, no network) writes the single emoji to `/output/entry.txt`:

```sh
python3 -P -s main.py
cat /output/entry.txt
```

The program enforces the competition gate in code (1–8 characters, exactly one emoji, no whitespace or control characters), writes atomically, and verifies the written bytes read back byte-for-byte. Two runs write byte-identical output.
